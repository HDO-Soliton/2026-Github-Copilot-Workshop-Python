# パターンC: ゲーミフィケーション要素の追加

## 概要
ゲーミフィケーション要素を導入し、ユーザーのモチベーション維持と継続利用を促進します。

## 目的
ゲーミフィケーション要素がモチベーション維持と継続利用に与える影響を測定する

## 実装機能

### 1. 経験値（XP）システム
- **説明**: 完了したポモドーロに応じてXPを獲得し、レベルアップする仕組み
- **実装内容**:
  - 1ポモドーロ完了 = 100 XP
  - レベル計算式: `レベル = floor(√(総XP / 100))`
  - レベルアップ時のアニメーション/通知
  - 現在のXP、レベル、次のレベルまでの進捗を表示
  - XPとレベルデータの保存（localStorage または SQLite）

### 2. 達成バッジシステム
- **説明**: 特定の条件を達成するとバッジを獲得
- **実装内容**:
  - バッジの種類:
    - 「初めの一歩」: 初回ポモドーロ完了
    - 「3日連続」: 3日連続でポモドーロ実施
    - 「今週の戦士」: 1週間で10回完了
    - 「集中マスター」: 累計50回完了
    - 「早起きの鳥」: 午前6時前にポモドーロ開始
    - 「夜更かし組」: 午後10時以降にポモドーロ完了
  - バッジ獲得時のアニメーション
  - バッジコレクション画面
  - バッジデータの保存

### 3. 週間/月間統計
- **説明**: より詳細なグラフ表示で進捗を可視化
- **実装内容**:
  - 週間統計:
    - 日別の完了ポモドーロ数（棒グラフ）
    - 週間合計集中時間
    - 週間平均集中時間
  - 月間統計:
    - 月間カレンダービュー（ヒートマップ形式）
    - 月間合計/平均集中時間
    - 完了率の推移（折れ線グラフ）
  - グラフライブラリの選定（Chart.js または D3.js）
  - 統計データの保存と集計

### 4. ストリーク表示
- **説明**: 連続日数をカウントし、モチベーションを維持
- **実装内容**:
  - 現在のストリーク日数表示
  - 最長ストリーク記録
  - ストリーク継続のための炎アイコン
  - ストリーク途切れ時の励ましメッセージ
  - 連続達成報酬（特別バッジ）
  - ストリークデータの保存

## 技術的検討事項

### フロントエンド
- JavaScript（ゲーミフィケーションロジック）
- Chart.js または D3.js（グラフ表示）
- CSS アニメーション（バッジ獲得、レベルアップ）

### バックエンド（オプション）
- Flask API: `/api/stats`, `/api/badges`, `/api/achievements`
- SQLite: ユーザーデータ、統計、バッジの永続化
- データモデル設計

### 実装ファイル
- `1.pomodoro/static/js/gamification.js` - ゲーミフィケーションロジック
- `1.pomodoro/static/js/stats.js` - 統計計算とグラフ表示
- `1.pomodoro/static/js/badges.js` - バッジ管理
- `1.pomodoro/static/css/gamification.css` - ゲーミフィケーションUI
- `1.pomodoro/templates/stats.html` - 統計画面（新規）
- `1.pomodoro/templates/badges.html` - バッジコレクション画面（新規）
- `1.pomodoro/api.py` - Flask API（オプション）
- `1.pomodoro/models.py` - データモデル（オプション）

### データ構造
```javascript
{
  xp: 0,
  level: 1,
  totalPomodoros: 0,
  currentStreak: 0,
  longestStreak: 0,
  lastCompletionDate: null,
  badges: [],
  history: [
    { date: '2026-02-24', pomodoros: 5, focusMinutes: 125 }
  ]
}
```

- [ ] 最低6種類のバッジが実装されている
- [ ] バッジ獲得時にアニメーションが表示される
- [ ] 週間統計グラフ（棒グラフ）が表示される
- [ ] 月間統計（カレンダーヒートマップ）が表示される
- [ ] ストリーク日数が正確にカウントされる
- [ ] すべてのゲーミフィケーションデータが永続化される
- [ ] 既存の機能（タイマー操作、通知等）が正常に動作する
