# パターンB: カスタマイズ性の向上

## 概要
ユーザーが自分の好みや作業スタイルに合わせてタイマーをカスタマイズできる機能を追加します。

## 目的
個人の好みに合わせた設定がユーザー継続率に与える影響を測定する

## 実装機能

### 1. 時間設定の柔軟化
- **説明**: 固定の25分ではなく、複数の時間オプションから選択可能
- **実装内容**:
  - 集中時間: 15分 / 25分 / 35分 / 45分から選択
  - UIに時間選択ドロップダウンまたはボタンを追加
  - 選択した時間設定を localStorage に保存

### 2. テーマ切り替え
- **説明**: 複数のテーマを用意し、ユーザーが選択可能
- **実装内容**:
  - ダークモード: 暗い背景、目に優しい配色
  - ライトモード: 明るい背景、クリアな配色
  - フォーカスモード: ミニマルデザイン、最小限の要素のみ表示
  - テーマ切り替えボタンまたは設定パネル
  - 選択したテーマを localStorage に保存

### 3. サウンド設定
- **説明**: 各種サウンドのオン/オフを個別に設定可能
- **実装内容**:
  - 開始音: タイマー開始時のサウンド
  - 終了音: 集中時間終了時のベル
  - Tick音: 秒針のようなカチカチ音（オプション）
  - 各サウンドのオン/オフ切り替え
  - 設定パネルUIの実装
  - 設定を localStorage に保存

### 4. 休憩時間カスタマイズ
- **説明**: 休憩時間を柔軟に設定可能
- **実装内容**:
  - 休憩時間: 5分 / 10分 / 15分から選択
  - 提案ダイアログまたは設定パネルで選択可能
  - 選択した休憩時間を localStorage に保存

## 技術的検討事項

### フロントエンド
- JavaScript（設定管理クラス）
- CSS（テーマ切り替え用のクラス定義）
- localStorage（設定の永続化）

### 実装ファイル
- `1.pomodoro/static/js/settings.js` - 設定管理
- `1.pomodoro/static/css/themes.css` - テーマ定義
- `1.pomodoro/templates/index.html` - 設定UIの追加
- `1.pomodoro/static/js/audio-manager.js` - サウンド管理

### データ構造
```javascript
{
  focusDuration: 25, // 15, 25, 35, 45
  breakDuration: 10, // 5, 10, 15
  theme: 'light', // 'light', 'dark', 'focus'
  sounds: {
    start: true,
    end: true,
    tick: false
  }
}
```

## 受け入れ条件（DoD）

- [ ] 集中時間を4つのオプション（15/25/35/45分）から選択できる
- [ ] 休憩時間を3つのオプション（5/10/15分）から選択できる
- [ ] 3つのテーマ（ダーク/ライト/フォーカス）を切り替えられる
- [ ] 各サウンド（開始/終了/tick）を個別にオン/オフできる
- [ ] すべての設定がブラウザをリロードしても保持される
- [ ] 設定変更が即座に反映される
- [ ] 既存の機能（タイマー操作、通知等）が正常に動作する
- [ ] 設定UIが分かりやすく使いやすい
